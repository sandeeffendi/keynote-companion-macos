## Development Workflow

Repository ini menggunakan `main` sebagai branch utama dan stabil.

### Branch Policy

- `main` adalah branch utama yang berisi kode stabil.
- Tidak diperbolehkan melakukan direct push ke `main`.
- Semua perubahan harus dilakukan melalui Pull Request.
- Pull Request wajib direview sebelum merge.
- Conversation pada Pull Request harus diselesaikan sebelum merge.
- Force push dan delete branch `main` tidak diperbolehkan.

### Branch Naming

Gunakan format branch berikut:

```text
feature/<nama-fitur>
bugfix/<nama-bug>
hotfix/<nama-hotfix>
